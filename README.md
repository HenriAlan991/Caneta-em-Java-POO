# Caneta em Java POO

Projeto de estudo em **Java** com **Programação Orientada a Objetos (POO)**.

## Sobre o projeto

Este código foi feito como exercício de fixação dos conceitos de **classes**, **objetos** e **métodos** em Java Orientado a Objetos.

O programa modela uma caneta, com atributos como cor, tamanho da ponta, tinta restante e estado da tampa, e com métodos que representam ações reais, como abrir, fechar, rabiscar e mostrar o status.

## Aviso

Todo o código deste projeto foi escrito por mim, como parte do meu processo de aprendizado. A inteligência artificial foi utilizada **somente para gerar este README**.

## Estrutura

- `Caneta.java`: classe com atributos e métodos da caneta
- `main.java`: classe principal que cria os objetos e testa os métodos

## Conceitos praticados

- Classes e objetos
- Atributos e métodos
- Uso do `this`
- Condicionais (`if/else`) dentro dos métodos

## Como executar

1. Compile os arquivos: `javac -d bin src/br/com/henrisufiatti/classecaneta/*.java`
2. Execute: `java -cp bin br.com.henrisufiatti.classecaneta.main`
